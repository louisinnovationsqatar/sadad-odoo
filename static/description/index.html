Checkout Modes Explained

v1.1 — Classic Redirect

Customer is redirected to the SADAD-hosted checkout page after clicking Pay. Uses a SHA-256 SHA hash signature generated from sorted parameters. Simple and widely supported. Best for merchants who want a straightforward integration.

v2.1 — Enhanced Redirect

Customer is redirected to SADAD's enhanced checkout page. Uses AES-128-CBC encrypted checksum with a random 4-char salt for tamper prevention. Recommended for most merchants — best balance of security and simplicity.

v2.2 — Embedded Payment Form

The SADAD payment form is embedded directly in your Odoo checkout page via iframe. Customer never leaves your website. Requires HTTPS (SSL) on your domain. Uses the same AES-128-CBC checksum as v2.1. Best for premium user experience.

Quick Setup (5 Steps)

  1. Install the module via Odoo Apps or by placing it in your addons path and upgrading the module list.
  2. Go to Invoicing → Configuration → Payment Providers and find "SADAD" in the list.
  3. Enter your credentials: Merchant ID, Secret Key, and Website name (all available from panel.sadad.qa).
  4. Copy the Callback URL and Webhook URL shown in the module settings and paste them into your SADAD merchant panel.
  5. Set state to "Enabled" and test with SADAD test credentials. Switch to production when ready.

Refunds

Full refunds are supported via the SADAD API. To issue a refund:

  • Go to the payment transaction in Odoo
  • Click the Refund button (standard Odoo payment workflow)
  • The module authenticates with SADAD API and submits the refund

Limitations: SADAD only supports full refunds (no partial). Refunds must be made within 3 months of the original transaction. Transaction must be in Success status.
